## 🚀 Featured Projects

### 🤖 Hansraj College AI Chatbot
- Developed a Retrieval-Augmented Generation (RAG) based chatbot to provide context-aware responses to college-related queries.
- Integrated LLMs with optimized retrieval pipelines using Python, LangChain, and FAISS.

### 🧠 Hinglish Sarcasm Detection
- Developed a Deep Neural Network for sarcasm classification using PyTorch.
- Applied Optuna for hyperparameter optimization.
- Achieved **94.10% accuracy and 0.9459 F1-score** on the test dataset.

### 🎬 Sequential Recommendation System
- Explored LRU-based sequential recommendation architectures using the MovieLens dataset.
- Worked with sequence modeling and recommendation evaluation metrics including Recall@K and NDCG@K.
